`setting-canon-integration.md` Core Rule #2 (line ~84-89) + UI
Requirements #1 (line ~625-629): Character Card unconditionally shows
`true_identity` for any `is_major_canon=true` NPC currently in disguise,
at all times, with zero player action required. `situation-encounter-
generation.md`'s `investigate` envelope (line 222) is a generic,
always-available action (`gate = true`) — not a dedicated identity-
investigation mechanic — so there's no gameplay verb this omniscience is
"skipping," but it does guarantee that discovery-through-play never
happens for exactly the NPCs players care most about (major canon
characters), while it's preserved only for minor/lower-stakes NPCs
(who still show "đang che giấu/dịch dung," no forced reveal).

**The tension**: this GDD's own frontmatter (line 6) claims to be "nền
cho aesthetic Discovery & đặc quyền xuyên không" — but the mechanic as
specified removes exactly the exploratory-discovery dynamic (uncovering
who someone really is) for its highest-value targets. This is by design
— it IS Pillar 1's "kẻ biết trước" fantasy (Player Fantasy section,
"trực tiếp" tier) — so it's not a bug, but the self-declared aesthetic
label is a mismatch: what actually remains "discoverable" for major-
canon identity is not *who* (handed to the player for free) but *what
happens as a result of knowing* (behavioral/social discovery, more
Expression/Fantasy than Discovery per MDA). `game-concept.md` line 109
scores Discovery as a low-priority aesthetic overall for this game
("Thế giới AI mô phỏng liên tục... khám phá phản ứng khách quan"), which
softens the practical stakes of this mismatch but doesn't resolve the
internal labeling contradiction inside this GDD.

**How to apply**: if this GDD is revised, either drop the "Discovery"
claim from the frontmatter's aesthetic list for this specific mechanic,
or reframe Rule #2's Discovery contribution as "discovering the
*consequences* of known identity" rather than the identity itself — avoid
citing Discovery as justification for a mechanic that structurally
forecloses it for its primary target population (major canon NPCs).
