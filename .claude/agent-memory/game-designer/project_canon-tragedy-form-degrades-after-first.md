`setting-canon-integration.md` Player Fantasy (round 1 revision,
2026-08-08) defines 2 valid forms of the "phá vỡ định mệnh" peak: (A)
deliberate break + refuse to rescue, (B) "bi kịch thụ động" — an
unintended consequence (e.g. a routine combat kill turns out to have
broken a canon premise) where the player later realizes the cost was
real. Mechanically both routes use the identical D.1 eager-break path
(`alive` is non-reversible) with zero pre-commitment warning (Open
Questions ND-3 explicitly closed: info-only *after* the event, no
foreshadowing — this is required by Pillar 1's "no plot armor,
never announced" credibility, not an oversight).

**The gap**: form (B)'s claim to be a standing, repeatable peak
experience — co-equal with (A) — doesn't survive contact with the MVP's
own content budget. There are only 3 NPCs and 2-3 canon events. The
*first* time a player accidentally triggers an eager break, they had no
way to know and can genuinely feel "the moment the cost became real."
Every subsequent kill within the same playthrough, the player now KNOWS
combat can break canon irreversibly — so any further "unintended"
breaks are no longer experienced as innocent tragedy, they read as
informed risk (closer to form A) or, worse, as "the game already taught
me this once, why am I being punished again with no new information."
Full Vision's larger roster would dilute this (more never-yet-surprised
NPCs), but MVP's tiny cast makes dạng B structurally a one-time beat,
not a durable parallel fantasy path the way dạng A is.

**Not blocking** — this is inherent tension from Pillar 1's own
no-forewarning requirement, not a fixable oversight, and the doc never
claims A/B are mechanically distinguished in real time (it's about
player prior knowledge, not system state). Whether (B) reads as
"meaningful tragedy" vs "arbitrary/unfair" depends entirely on AI
narration quality — already correctly flagged ADVISORY under AC-47,
but AC-47 tests general consistency-with-locked-resolution, not
specifically the emotional valence of surprise-as-tragedy vs
surprise-as-unfairness for this one scenario.

**How to apply**: if revisited, recommend (1) a narrow addition to
AC-47's golden-scenario set specifically probing dạng B's felt
fairness, and (2) a documented acknowledgment in the GDD text that
dạng B is realistically a first-encounter-only beat within MVP's
roster size — an accepted scope limitation, not silently assumed to
recur.
