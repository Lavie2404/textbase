`setting-canon-integration.md` Open Questions (round 1, 2026-08-08)
added 2 MVP authoring rubric constraints: (a) at least 1 MVP canon
event must use `on_break=vanish` on a premise OUTSIDE the romantic
category (e.g. political/military/territorial — countering the fact
every worked example in the doc is the Song Tu partner / "Tiểu Vũ"
romance beat); (b) the MVP setting pack must include at least 1
`is_major_canon=false` NPC actively hiding their identity, so the
"che giấu, không lộ danh tính thật" branch of UI Requirement #1/AC-02
actually exercises in the shipped MVP, not just Full Vision.

Core Rule #1 caps the MVP setting pack's data explicitly at "3 NPC +
2-3 sự kiện canon" — the SAME roster [[project_song-tu-partner-combat-dead-zone]]
NPC Affinity uses (1 thù địch, 1 hảo cảm/Song-Tu-preset, 1 trung lập),
not a separate larger canon cast. There is no budget headroom for extra
named characters to satisfy ND-1/ND-2 independently.

**Verdict**: feasible, not blocking — but only if ND-1 and ND-2 are
DELIBERATELY combined onto the SAME 1 NPC (the hostile or the neutral
one, whichever isn't the Song Tu partner): that NPC anchors the
non-romantic vanish premise (e.g. their survival/death gates a
political/military event) AND is the non-major NPC hiding their real
identity (revealed through that same event). The GDD's Open Questions
text currently lists (a) and (b) as two independent bullets without
noting they should/can overlap — an author following each literally
might feel pressured to invent a 4th named character the data budget
doesn't provision for.

**How to apply**: recommend adding one explicit sentence to Open
Questions instructing authors to satisfy ND-1+ND-2 via the same NPC,
given the fixed 3-NPC ceiling — cheap, avoids a false "need more
content" panic during MVP authoring.
