User is a solo developer (also the sole intended player) building "Vô Danh
Lục" (`design/gdd/game-concept.md`), a personal, non-commercial, Vietnamese-
language xianxia interactive-fiction RPG on Godot 4.6/GDScript. There is no
team, no monetization, and no external audience — economic balance decisions
should be judged purely against the stated design pillars (Thế Giới Khách
Quan, Hệ Quả Thực Sự, Sức Mạnh Có Logic, Tường Thuật Sống Động, Tự Do Nhập
Vai), not against live-service/retention metrics.

User asks for adversarial/red-team style review of progression and economy
formulas before they get formalized into a GDD — wants concrete numeric
failure-scenario examples (not vague "this could be unbalanced" statements),
in Vietnamese, structured by the specific question asked. See
[[project-vo-danh-luc-progression-risks]] for the concrete formulas and
risks already surfaced this way.

**How to apply**: when reviewing this user's formulas, always work out at
least one worked numeric example per identified risk (turns-to-level,
percentage stacking, bậc-gap penalty math) rather than describing the risk
abstractly. Assume the user prefers rigor and precision over reassurance.
